# CodSoft AI Internship - Task 3: Image Captioning

This repository contains two implementations for the Image Captioning AI task:
1. **Transformer Approach (`image_captioning.py`):** Uses a pre-trained Vision-Language model (BLIP) to fetch images from live web URLs and generate accurate captions.
2. **Traditional Approach (`traditional_image_captioning.py`):** Implements a classic CNN encoder (ResNet50) for feature extraction.
